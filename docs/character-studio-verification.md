- 2.7.0 将新手主流程压缩为“添加参考 → 确认角色 → 制作与下载”三步；标准角度与一致性检查合并在第二步，一致性检查由逐张通过再锁定改为三张结果一次确认并进入制作页，单张不一致可直接重新生成。

## 使用与数据

本次开发工作区为项目根目录。

修复版正在默认地址 `http://127.0.0.1:8797` 运行。旧进程与临时验收进程均已停止，只保留一个 2.7.0 服务。

项目保存在 `data/character-studio/projects/`。升级请保留 config、data、output。导入旧项目时选择包含 project.json 和 assets 的单个 project-… 文件夹，同名项目不会覆盖。

参考原图仅供当前会话使用，不落盘。待审核候选只保存在内存，两小时后过期；刷新页面不会自动恢复未确认候选，服务重启不会自动重新提交。满意后及时点击“确认使用”。改变身份请在“角色管理”中创建新版本；旧版本保留。

导出展示板不调用模型。ZIP 下载分两步：点击“导出模型参考包”，再点击“下载模型参考包 ZIP”。模型参考包是图片与描述文件，不包含三维网格或模型权重。
