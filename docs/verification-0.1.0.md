发布前另对 Git 暂存内容复核密钥、用户数据、来源未确认的人像、个人工作路径、必要构建产物及文档链接。敏感配置、用户作品和本地验收截图继续由 `.gitignore` 排除。

角色测试的 jsdom 环境会提示 Canvas `getContext` 未实现，测试整体通过；这不替代真实浏览器的完整视觉验收。

本次未调用付费图片接口，未验证供应商余额、模型权限、实时可用性、真实人物一致性或出图质量。未重建或上传便携二进制包，也未完整复测 macOS / Linux。发布范围为可在本机和可信局域网试用的源码标签。
