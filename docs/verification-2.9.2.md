# Gugu Image Edit 2.9.2 验证记录

日期：2026-10-05。视觉主题：Aurora Tech Workbench。

## 改动范围

- 建立唯一的工作台对齐变量 `--workbench-shell-width`，替代顶部、步骤、主工作区、写真、角色、3D、结果区和页脚各自独立的最大宽度。
- 桌面端品牌左缘、操作区右缘、八模块导航、四步条、左右工作卡和页脚共用同一左右边界。
- 移除桌面工作区额外的 24px 横向内缩，使可见卡片边框直接落在统一轨道上；列间距固定为 22px。
- 图片生成、扩展、精确编辑、产品换背景、材质迁移、Q版表情包和人像创作的双栏卡片继续等高，标题区与底边差值均为 0。
- “拍写真 / 做模卡 / 角色素材”顶部中心与角色工作区统一轨道；3D 模型预览、结果卡、写真系列卡也纳入同一轨道。
- 768px 与 390px 下继续使用同一逻辑：分别保留 16px 与 10px 外边距，导航、步骤、工作卡和页脚精确对齐并自动单列。
- 版本 2.9.1 → 2.9.2；更新页面资源查询、离线缓存代号和便携版说明。
- 不修改模型提示词、API 协议、业务参数、任务队列、数据格式及保存路径。
