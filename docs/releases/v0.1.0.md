# v0.1.0 · 首个公开预览版

- 图片生成、扩图、精确编辑、产品换背景、材质迁移与 Q 版表情包。
- 人像写真、角色模卡、规范图、展示板及模型参考包导出。
- 本地 3D 模型预览、布光取景与 PNG 截图。
- 局域网账号、管理员审核、积分管理、任务队列和用户数据隔离。
- 提供中文安装文档与 MIT 许可；公开源码排除密钥、用户数据和未确认人像素材。

安装 Node.js 24 LTS（最低 22.13），在项目根目录运行 `node scripts/quick-start.js`，然后按 README 配置图片 API Key。

本次提供源码标签，未附带便携二进制包。AI 生成依赖第三方付费接口，真实出图质量与人物一致性需人工验收；当前版本面向本机与可信局域网试用。
