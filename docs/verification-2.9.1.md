# Gugu Image Edit 2.9.1 验证记录

日期：2026-10-05。视觉主题：Aurora Tech Workbench。

## 改动范围

- 顶栏改成两层信息架构：品牌与常用操作位于上层，八个工作模块占据完整下层导航，不再缩成中间的小型胶囊。
- 桌面导航为八列等宽大入口；每项统一 38px 图标容器、文字基线、悬停与紫青选中态。宽屏下导航最大扩展到 2320px。
- 工作区改为流动宽度：1920px 视口为 1560px，2560px 视口为 2080px，超宽屏最高 2160px；步骤条与页脚使用同一响应规则。
- 统一主编辑卡与参数卡的拉伸规则、700px 基准高度、90px 标题区、分隔线和内边距，修复图片扩展与精确编辑页面左右卡片底边不齐的问题。
- 统一表单控件宽度、双列字段底线、结果操作区、产品双上传卡、写真用途导航等局部对齐。
- 980px 以下导航改为可横滑大图标列表、工作区自动单列；620px 以下压缩品牌与操作区，但保留清晰点击尺寸。
- 主程序 2.9.0 → 2.9.1；更新页面版本、离线缓存代号和便携版说明。
- 不修改模型提示词、API 协议、业务参数、队列、数据格式及保存路径；无新增网络字体、图标 CDN 或运行时依赖。
