GuGu AI Visual Studio 3.0.0 局域网团队版使用说明
================================

1. 请先把整个 ZIP 压缩包解压到一个普通文件夹。
2. 打开“GuGu AI Visual Studio Portable”文件夹。
3. 双击 quick-start.cmd 启动。
4. 浏览器打开后使用管理员账号登录；黑色启动窗口需要一直保持打开。
5. 首次启动会在黑色窗口显示一次性管理员密码，请妥善保存并登录后在管理后台重置。
6. 管理员在右上角“接口设置”填写团队共用的 API Key，普通用户不能查看或修改。
7. 同事通过服务器电脑的局域网 IP 加端口 8797 访问，注册后由管理员审核并分配积分。
8. “3D模型预览”无需 API Key，可直接载入 GLB、GLTF、OBJ、FBX 或 STL 并在本机取景截图；浏览器记录按登录用户隔离。
9. “人像创作工作室”共用管理员配置的 147 图片和火山 Seedream 渠道，可选拍写真、做模卡和角色素材。
10. 用户、任务、积分和审计保存在 data/team.db；项目、写真和输出文件按用户隔离。
11. 模型参考包需先点击“导出模型参考包”，再点击“下载模型参考包 ZIP”；导出本身不调用模型。
12. docs 文件夹内附有局域网完整部署手册，以及“不知道服务器 IP、通过电脑名称访问”的简化部署手册。

重要提醒
--------

- 不需要另外安装 Node.js，runtime 文件夹中已经包含运行环境。
- 不要只把 quick-start.cmd 单独拖到桌面，否则程序找不到其他文件。
- 如需桌面图标，请双击 install-desktop.cmd 创建快捷方式。
- 如果 Windows 安全提示阻止运行，请确认压缩包来源可信后再选择运行。
- 只在公司“专用网络”开放 TCP 8797，禁止映射到互联网。
- 团队数据保存在程序文件夹内的 config、data 和 output 目录，三者必须一起备份。
- 更新已有安装时请先停止服务并完整备份 config、data 和 output。
- 3D 模型与场景保存在浏览器本地站点数据中；清理浏览器数据前请先下载需要保留的截图。
- 升级或移动程序前，请先关闭黑色启动窗口。
- 如果程序已经运行，再次双击 quick-start.cmd 会直接打开现有页面；不会再显示“端口已被占用”。
