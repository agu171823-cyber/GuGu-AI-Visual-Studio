# GuGu AI Visual Studio

**把文字、参考图和 3D 取景，变成可下载的 AI 视觉作品。**

GuGu AI Visual Studio 是一个可部署在个人电脑或公司局域网的 AI 视觉创作工作台。你可以在同一个浏览器界面里完成图片生成、扩图、局部编辑、产品换背景、材质迁移、表情包、人像写真与角色模卡制作，也可以先用本地 3D 模型布光取景，再把截图交给 AI 继续创作。

当前版本：**0.1.0 · 首个公开预览版**。支持个人使用，也支持多人注册、管理员审核、积分分配、任务排队与用户数据隔离。发布说明见 [v0.1.0](docs/releases/v0.1.0.md)。

> **运行方式：本机 / 内网服务 + 浏览器界面 + 自备图片 API Key。**
> 程序负责界面、工作流、项目和文件管理；AI 图片由配置的上游渠道生成。3D 预览与截图在浏览器本机完成。无需在本机部署图片模型或配置 CUDA；AI 生成需要联网，费用由上游供应商收取。

```text
文字 / 参考图片 ──→ 选择功能、模型与参数 ──→ AI 生成 ──→ 对比、下载与归档
本地 3D 模型   ──→ 布景、材质、灯光与取景 ──→ PNG 截图 ──→ 下载或继续 AI 创作
```

## 能做什么

| 想完成的事情 | 使用功能 | 需要准备什么 | 会得到什么 |
| --- | --- | --- | --- |
| 从零制作海报画面、概念图、产品视觉 | 图片生成 | 文字描述，可选 0–10 张参考图 | 1 张生成图片 |
| 把竖图扩成横图，补全画面四周 | 图片扩展 | 1 张原图、四边扩展范围，可选填充提示 | 1 张补全后的图片 |
| 修改指定区域、颜色、物体或细节 | 精确图片编辑 | 1 张原图、编辑要求，可选标注与最多 9 张额外参考图 | 1 张编辑后的图片 |
| 把产品放进指定场景 | 产品换背景 | 1 张产品图 + 1 张背景图 | 1 张融合场景、阴影与光影的产品图 |
| 给同一主体换成玉石、金属、织物等材质 | 材质迁移 | 1 张主体 / 结构图 + 1 张材质参考图 | 1 张迁移材质后的图片 |
| 把人物或宠物做成聊天表情 | Q版表情包大师 | 1 张照片，选择 6 / 9 / 12 格及文案方式 | **1 张完整宫格图** |
| 用同一个人拍不同风格写真 | 人像创作工作室 → 拍写真 | 1–4 张同一成年人的参考图、风格与参数 | 先生成 1 张主肖像，可再扩展成 4 张系列 |
| 制作真人模卡、写实角色设定与连续角色素材 | 人像创作工作室 → 做模卡 / 角色素材 | 1–4 张获授权的成年人或成年外观写实角色参考图 | 规范图、派生图片、展示板 PNG、模型参考包 ZIP |
| 用三维模型确定构图、光影和材质 | 3D模型预览 | 1 个 GLB / GLTF / OBJ / FBX / STL 文件 | PNG 取景截图，可发送到图片生成、精确编辑或材质迁移 |

适合设计师、电商视觉人员、人像与角色创作者，以及需要统一管理图片接口和使用额度的小型团队。

生成式编辑会尽量遵循原图与提示词，但人物一致性、Logo、文字、产品结构和局部细节仍需人工验收。精确编辑的标注用于引导模型理解修改位置。

## 快速开始

### 1. 获取程序并启动

**Windows 便携包**

如果仓库的 Releases 提供 `GuGu-AI-Visual-Studio-Portable-0.1.0-win-x64.zip`，下载后完整解压，双击根目录的：

```text
quick-start.cmd
```

便携包包含 `runtime/node.exe`，无需另装 Node.js，也无需执行 `npm install`。不要只复制启动脚本，需保留完整目录结构。

**GitHub 源码包 / Git 克隆**

通过当前仓库的 **Code → Download ZIP** 获取并解压，或使用 Git 克隆。安装 **Node.js 24 LTS**，项目最低要求为 **Node.js 22.13.0**。

在项目根目录打开终端：

```sh
node --version
node scripts/quick-start.js
```

Windows 也可以直接双击 `quick-start.cmd`。启动脚本会在 `.env` 不存在时复制 `.env.example`，并尝试自动打开浏览器：

```text
http://127.0.0.1:8797
```

**正常运行无需安装 npm 依赖。** 仓库中的角色模块前端和服务端已预编译，Three.js 与 HDR 环境资源也随程序提供。仅修改角色模块源码时才需要安装该模块的开发依赖。

保持启动终端打开，按 `Ctrl+C` 停止服务。服务已启动时，再次运行快速启动脚本会打开现有页面。

### 2. 登录初始管理员

- 默认用户名：`admin`。
- 第一次启动且未设置 `ADMIN_PASSWORD` 时，终端会显示一次性初始随机密码，请保存后登录。
- 也可以在首次启动前复制 `.env.example` 为 `.env`，自行填写 `ADMIN_PASSWORD`。
- 登录后可在管理后台重置密码。**数据库创建后，修改 `.env` 中的密码不会重置已有账号。**

### 3. 配置图片接口

用管理员账号打开右上角 **接口设置**，为准备使用的渠道填写 Base URL 和自己的 API Key，然后保存。至少配置一个渠道即可开始 AI 创作；普通用户使用管理员已配置的渠道。

| 渠道 | 程序默认 Base URL | 程序内置模型 ID |
| --- | --- | --- |
| 147 图片 | `https://147ai.com/v1` | `gpt-image-2.5-flare`、`gpt-image-2.5-sunburst` |
| 火山 Seedream | `https://ark.cn-beijing.volces.com/api/v3/images/generations` | `doubao-seedream-5-0-flash-260915`、`doubao-seedream-5-0-pro-260628` |

这些名称和 ID 来自当前版本的内置配置；实际可用性、模型权限、价格和输出支持取决于上游账号。两种渠道的 Key 分别配置，不能互相替代。火山渠道还支持设置水印。

147 图片使用 Images 接口：无参考图的图片生成请求发送至 `/images/generations`，参考图生成与编辑发送至 `/images/edits`。更换 Base URL 时，目标服务需兼容这些请求格式；其他供应商不保证直接兼容。火山渠道可填写 API 根地址，也可填写完整的图片生成地址。

Key 保存在服务端 `config/settings.json`，浏览器只接收配置与脱敏状态。**部署位置在本地不代表参考图片不会离开本地：提交 AI 生成时，任务所需的图片和提示词会发送到所选上游渠道。**

### 4. 完成第一张图片

1. 进入 **图片生成**。
2. 选择已经配置的渠道与模型。
3. 输入描述，例如：`一只薄荷绿色的陶瓷杯放在浅灰桌面上，柔和侧光，简洁产品摄影，背景干净，无文字。`
4. 首次使用可选 `1:1`、`1K`，点击生成。
5. 等待任务完成，在结果区查看并下载图片。

无需上传参考图就可以文生图。添加参考图后，点击缩略图可插入 `@图片1`、`@图片2` 等编号，并在描述中说明每张图的作用。

## 输入条件

### 图片格式、大小与数量

| 功能 | 输入格式 | 单文件上限 | 数量与顺序 |
| --- | --- | --- | --- |
| 图片生成 | 推荐 PNG / JPEG / WebP | 30 MB | 0–10 张；纯文字生成时可不上传 |
| 图片扩展 | 推荐 PNG / JPEG / WebP | 30 MB | 仅 1 张原图 |
| 精确图片编辑 | 推荐 PNG / JPEG / WebP | 30 MB | 1 张原图 + 0–9 张额外参考图，总计最多 10 张 |
| 产品换背景 | **PNG / JPEG / WebP** | 30 MB | 恰好 2 张；产品图在前，背景图在后 |
| 材质迁移 | 推荐 PNG / JPEG / WebP | 30 MB | 恰好 2 张；主体 / 结构在前，材质参考在后 |
| Q版表情包 | 推荐 PNG / JPEG / WebP | 30 MB | 仅 1 张人物或宠物照片 |
| 拍写真 | **PNG / JPEG / WebP** | 30 MB | 1 张主参考 + 最多 3 张补充参考 |
| 做模卡 / 角色素材 | **PNG / JPEG / WebP** | **15 MB** | 初始参考 1–4 张，需确认成年人及使用权 |
| 3D模型预览 | GLB / GLTF / OBJ / FBX / STL | **200 MB** | 通过模型文件选择器加载单个文件 |

一般图片通道的服务端还接受 BMP、GIF、TIFF、HEIC 和 HEIF 的图片 MIME 类型，但浏览器解码和供应商支持可能不同。为减少失败，建议先转为 PNG / JPEG / WebP；不支持把 PSD、PDF、SVG 或视频作为这些图片模块的输入，也不提供动图处理工作流。

主图片接口通过 Base64 传图，默认整个请求体上限为 **180 MB**，其中还包含原图快照、标注合成图等数据；Base64 本身也会增加体积。因此“最多 10 张、每张 30 MB”不代表能一次上传 300 MB。遇到请求过大时，先压缩图片或减少参考图。角色生成另有 **64 MB** 的整体请求限制。

### 准备素材时应注意什么

- **人物与角色：** 参考图应指向同一身份，面部清晰，尽量避免遮挡、强滤镜和多人混杂。写真及模卡 / 角色工作流要求人物为成年人或角色具有明确成年外观，并具备素材使用权。
- **产品换背景：** 产品边缘、文字和结构越清楚越好；背景图应提供可放置产品的空间。补充要求可留空，或说明位置、大小与光线。
- **材质迁移：** 第一张决定形状与构图，第二张提供表面材质；材质参考应能清楚展示纹理、反射或透光特征。可指定轻度 / 标准 / 强烈迁移及局部保护要求。
- **精确编辑：** 用点、框、箭头或画笔明确位置，再用文字说明修改内容及需要保留的部分；支持橡皮和撤销。
- **3D 模型：** 推荐使用资源完整嵌入的 GLB。当前入口选择单个模型文件，依赖额外 `.bin`、MTL 或贴图文件的模型可能无法完整呈现，建议先转换为资源内嵌格式。

### 文案长度

以下为当前界面的输入长度限制，填写时以页面计数与提示为准：

| 输入位置 | 长度上限 |
| --- | --- |
| 图片生成描述 | 5,000 字符 |
| 图片扩展填充提示 | 1,000 字符，可留空 |
| 精确编辑要求 | 1,200 字符 |
| 产品换背景补充要求 | 1,000 字符，可留空 |
| 材质说明 / 额外要求 | 分别为 300 / 1,000 字符 |
| 表情包单格文字 / 补充要求 | 分别为 12 / 600 字符 |
| 写真额外要求 | 1,000 字符；高级参数每项最多 500 字符 |

表情包文案建议使用 2–8 个常用汉字，选择“AI 随机热梗”时，由图片模型在同一次请求中构思文案和画面，不额外调用文案接口。

## 输出条件

### 图片生成：比例、档位与格式

支持 8 种比例：`16:9`、`9:16`、`2:3`、`3:2`、`3:4`、`4:3`、`21:9`、`1:1`。

- **147 图片：** 1K / 2K / 4K，标准 / 高清画质；当前图片生成界面不提供该渠道的格式切换。
- **火山 Seedream：** 1K / 1.5K / 2K，PNG / JPEG；Pro 可选择标准 / 快速提示词优化。
- **每次生成 1 张结果。** 档位是预设名称，不代表所有比例都具有相同长边；页面会显示实际请求尺寸。最终文件以供应商实际返回结果为准。

主图片任务单张返回结果最大 **80 MB**，角色资产最大 **30 MB**。结果文件按上游返回的实际 MIME 类型保存，不会仅修改后缀就转换格式；选择 PNG / JPEG 表示请求格式，下载时仍应检查实际结果。

### 图片编辑、扩图与双图任务

- **精确编辑：** 输出 1 张图片，可选 PNG / JPEG；提供 8 种比例的 1K / 2K 预设。初始尺寸会参考原图比例，提交前可自行选择。
- **图片扩展：** 四边分别设置 0–300% 扩展，支持拖拽与锁定原比例。GPT Image 2 系列的目标尺寸按 16 像素对齐，最长边不超过 3840 像素，长短边比不超过 3:1，总像素在 655,360–8,294,400 范围内。最终以页面计算的目标尺寸为准，超出比例会提示调整。
- **产品换背景：** 可选择跟随产品图或背景图比例；程序从可用预设中匹配接近该比例的尺寸，默认请求 PNG。
- **材质迁移：** 跟随主体 / 结构图比例匹配可用预设，默认请求 PNG。

双图任务的“跟随比例”不代表逐像素保留输入宽高。程序保存上游返回的实际图片，不保证生成后所有细节与输入逐像素一致。

### Q版表情包

| 选择数量 | 排列 | 请求尺寸 |
| --- | --- | --- |
| 6 格 | 3 列 × 2 行 | 2496×1664 |
| 9 格 | 3 列 × 3 行 | 2048×2048 |
| 12 格 | 3 列 × 4 行 | 1776×2368 |

输出是**一张带白色或近白背景的完整宫格图**，默认请求 PNG；当前没有自动拆分成独立贴纸或导出透明单格的步骤。中文由图片模型直接绘制，可能出现错字，需要检查后使用。

### 人像写真

进入 **人像创作工作室 → 拍写真**，上传主参考，可追加侧脸、发型或配饰参考，完成成年人和使用权确认，再选择风格、表情及参数。

工作室提供本地照片分析、三问风格推荐和 12 种风格。照片分析在本地完成；实际生成时参考图会发送给上游模型。

| 档位 | 方形 1:1 | 竖幅 2:3 | 横幅 3:2 |
| --- | --- | --- | --- |
| 1K | 1024×1024 | 1024×1536 | 1536×1024 |
| 2K | 2048×2048 | 1664×2496 | 2496×1664 |

首次只生成 **1 张主肖像**。满意后点击 **扩展为四张系列**，才会依次生成其余 3 张；每张分别调用接口并计费。支持逐张下载、重新生成与定向修改，失败时已完成图片仍保留。

也可以使用已确认角色的标准图拍写真，并把成片保存到该人物的独立作品库。写真默认不把参考原图写入历史；需要刷新后继续对比时，请在生成前勾选 **保存第一张参考图到本地历史**。

### 模卡与角色素材

在 **人像创作工作室 → 做模卡 / 角色素材** 中创建真人模卡或写实虚拟角色项目，基本流程为：

```text
创建项目 / 导入已有项目
  → 上传参考并分配用途
  → 确认身份基准照与正面全身双锚点
  → 补全六张规范图
  → 审核光照 / 角度 / 动作三项压力测试
  → 锁定身份版本
  → 制作模卡、表情、服装与动作派生素材
  → 导出展示板或模型参考包
```

六张规范图包括：**身份基准照、微侧半身、正面全身、侧面全身、背面全身、中性半身**。身份图建议使用同一模型，并逐张人工验收；改变身份需建立新版本。

- 参考图不落盘；已生成但尚未接受的候选图暂存在服务内存，须在 **2 小时内接受**。刷新会丢失页面中的未接受结果，重启服务会清空内存候选；已接受的项目与图片可重新打开。
- 最多允许 8 个运行中的角色请求，实际执行仍共用全局队列；候选内存达到限制后，需先接受或丢弃已有结果。
- **展示板 PNG：** 真人模卡为 A4 比例 `2480×3508`；虚拟角色为 `3072×2048`，在浏览器本地排版导出。
- **模型参考包 ZIP：** 需要六张 PNG 规范资产齐全、三项压力测试审核通过并锁定版本，包含六张 PNG、`character.json` 与 `README.md`。先点击导出，再点击下载 ZIP。
- 模型参考包用于后续建模或角色制作参考，**不包含三维网格、模型权重或可训练模型**。导出不会调用图片模型。
- 可导入本程序格式的单个 `project-…` 文件夹，需包含 `project.json` 与 `assets/`。上传请求总量不超过 **128 MB**，最多 500 个文件，`project.json` 不超过 8 MB，单个资产不超过 30 MB；同 ID 的项目不会被覆盖。此目录导入与模型参考包 ZIP 是不同用途。

### 3D 取景截图

支持双相机取景、移动 / 旋转 / 缩放、基础几何体、三类灯光、场景对象管理、材质通道、HDR 环境、阴影、GTAO、五种渲染风格及比例裁剪。

点击 **截取当前画面** 输出 PNG，自动隐藏辅助线与灯光图标。截图尺寸由浏览器渲染画布和所选裁切比例决定，当前没有独立的 4K 离线渲染导出设置。截图可下载，也可直接发送到图片生成、精确编辑或材质迁移。

模型解析、渲染和截图不调用图片 API、不消耗图片额度；主动提交后续 AI 生成时才产生上游费用。本地资源完整时，3D 预览可离线使用。

```dotenv
ADMIN_USERNAME=admin
ADMIN_PASSWORD=
ADMIN_INITIAL_BALANCE=100000
JOB_CONCURRENCY=1
MAX_REQUEST_MB=180
```

| 配置项 | 含义 |
| --- | --- |
| `HOST` | `.env.example` 默认为 `0.0.0.0`，允许局域网访问；仅本机使用可改为 `127.0.0.1` |
| `PORT` | 服务端口，默认 `8797` |
| `PUBLIC_ORIGIN` | 固定允许的访问来源，如 `http://192.168.1.20:8797`；多个地址用英文逗号分隔，包含协议及端口 |
| `ADMIN_USERNAME` | 初始化管理员用户名，默认 `admin`；已有数据库迁移时请保持一致 |
| `ADMIN_PASSWORD` | 仅创建管理员时使用；留空则首次创建时生成随机密码 |
| `ADMIN_INITIAL_BALANCE` | 初始管理员的团队积分，默认 `100000`，不等于上游账户余额 |
| `JOB_CONCURRENCY` | 全局同时执行的任务数，默认 `1`，支持 `1–4` |
| `MAX_REQUEST_MB` | 主图片接口请求体上限，默认 `180` MB；不改变单图与角色模块的独立限制 |

修改后重启服务。同事在浏览器访问部署电脑的局域网 IP，例如：`http://192.168.1.20:8797`。客户端无需安装 Node.js；局域网客户端的 `127.0.0.1` 指向客户端自己，不能用于访问部署电脑。

`PUBLIC_ORIGIN` 留空时接受当前访问主机名；填写后，写操作只接受配置来源及本机来源。建议部署电脑使用固定 IP 或内部域名，并只在防火墙专用网络中放行对应 TCP 端口。当前版本面向本机与可信局域网部署，不应直接做公网端口映射。

### 账号、积分和任务

1. 同事自行注册，账号初始为待审核，暂时不能登录。
2. 管理员审核账号并分配积分。
3. 用户登录后使用个人工作区；任务、生成图片、写真、角色项目和浏览器 3D 场景按用户隔离。
4. 管理员可管理账号启停、密码重置、接口配置、注册开关、功能积分价格、调用记录、内容占用与操作审计。

团队积分是程序内部的额度管理：提交任务时冻结，成功后结算，失败或程序重启中断时释放。**上游供应商仍按实际请求独立计费，释放团队积分不代表供应商退款。**

默认全局逐个执行任务，每位用户最多保留 10 个未完成的主图片队列任务。上游限流时，普通图片请求可能进行有限的 429 重试；角色生成不自动重试。网络失败或超过 15 分钟等待超时不会自动重新提交，需先核对上游状态，再决定是否手动重试。

### 桌面快捷方式与 PWA

Windows 双击 `install-desktop.cmd` 可创建桌面快捷方式。也可以在支持安装的 Edge / Chrome 中将工作台作为 PWA 独立窗口使用；安装入口是否显示取决于浏览器与访问来源，推荐本机地址或受信任 HTTPS。快捷方式和 PWA 都依赖本地服务运行，关闭服务后无法继续生成。

## 数据保存、备份与删除

以下路径均相对于**部署电脑的程序根目录**，不是访问者的电脑：

| 内容 | 保存位置 |
| --- | --- |
| 图片接口配置与 API Key | `config/settings.json` |
| 用户、会话、积分、任务、调用记录与审计 | `data/team.db`，SQLite WAL 模式 |
| 初始管理员的生成结果与对比图 | `output/` |
| 其他用户的生成结果与对比图 | `output/users/<用户ID>/` |
| 初始管理员的角色项目与写真作品库 | `data/character-studio/projects/`、`data/portrait-album/` |
| 其他用户的角色项目与写真作品库 | `data/users/<用户ID>/character-studio/projects/`、`data/users/<用户ID>/portrait-album/` |
| 3D 模型、场景设置与最近截图 | 访问者浏览器的 IndexedDB，按用户 ID 隔离 |

主图片任务成功后会归档结果。除写真默认不存参考原图外，有输入图的新任务还会保存用于历史对比的原图快照；扩图保存的是用于对比的扩展合成图。历史对比图按任务固定关联，旧记录没有原图时会明确提示。

历史支持勾选、全选与批量删除；确认后会同时删除对应的本地结果文件和对比图，运行中的任务不能删除。需要留存的作品请提前下载或备份。

完整备份时，先停止服务，再复制 **`config/`、`data/`、`output/`**；如需保留部署参数，另行妥善备份 `.env`。3D 浏览器数据不在服务器备份中，清理浏览器数据、更换设备或访问来源可能导致无法恢复上次场景。

```text

quick-start.cmd            Windows 快速启动

```

### 启动与检查

以下命令在根目录执行；Windows PowerShell 如阻止 `npm.ps1`，可将 `npm` 改为 `npm.cmd`。

```sh
# 启动服务；首次使用请先准备 .env，启动后手动访问 8797 端口
npm start

# 主程序测试，不调用付费接口
npm test

# 仅在开发角色模块时：安装该模块依赖
npm --prefix modules/character-studio ci

# 角色模块类型检查、测试及构建

npm run build:character
```

角色模块构建更新 `public/character-studio/` 与 `server/character-studio.cjs`。发布源码供用户免安装运行时，需同时包含这些构建产物与本地静态资源。

自动化测试使用模拟图片 / 接口，不验证真实供应商余额、权限、人物一致性或出图质量。本次公开版本检查见 [0.1.0 验证记录](docs/verification-0.1.0.md)。此前内部迭代记录保留原编号，见 [3.0.0 历史验证记录](docs/verification-3.0.0.md)；角色模块说明见 [模块 README](modules/character-studio/README.md)。

### 制作 Windows 便携包

在联网的 Windows 开发电脑上双击 `build-portable.cmd`。脚本从 Node.js 官方下载运行时并进行 SHA-256 校验，在 `release/` 中生成包含运行时的 Windows x64 ZIP。

ARM64 打包：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-portable.ps1 -Architecture arm64
```

发布包会排除个人 `.env`、接口密钥、团队数据库、用户项目及生成图片。Windows 启动、桌面安装和便携打包使用 `.cmd` / PowerShell；macOS / Linux 使用前述 Node.js 命令启动，Windows 脚本不适用。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 提示找不到 Node.js | 源码运行需安装符合要求的 Node.js；便携包请完整解压并检查 `runtime/node.exe` |
| 提示 `node:sqlite` 不存在或启动报版本错误 | 检查终端实际使用的 Node.js 版本，升级到项目要求的版本 |
| 页面没有自动打开 | 保持服务运行，手动访问 `http://127.0.0.1:8797`；若修改了端口，请使用新端口 |
| 提示端口占用 | 若已有本程序在运行，使用现有页面；其他程序占用时关闭占用程序或修改 `.env` 中的 `PORT` |
| 看不到接口设置 | 需要管理员账号；普通用户不具有配置权限 |
| 注册后不能登录 | 等待管理员审核；审核后还需有足够积分才可提交生成任务 |
| 本地积分足够但生成仍失败 | 检查上游 Key、余额、模型权限、网络和失败说明；本地积分与上游余额独立 |
| 请求过大 / 图片无法读取 | 按模块限制减少数量、压缩素材，优先转换为 PNG / JPEG / WebP |
| 局域网无法访问或提示来源不受信任 | 检查服务是否运行、`HOST`、部署电脑 IP、防火墙及 `PUBLIC_ORIGIN` 中的协议、主机和端口 |
| 模型没有贴图或无法加载 | 优先改用资源内嵌的 GLB，检查文件是否依赖外部资源，并确认浏览器具备可用的 WebGL 渲染能力 |
| 角色候选图刷新后消失 | 未接受的候选不属于持久化项目；生成后及时接受，已保存项目可从列表重新打开 |
